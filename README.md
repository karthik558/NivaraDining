# Lilac IRD

Responsive in-room dining experience for Lilac Hotels.

## Stack

- Vue 3
- Vue Router
- Tailwind CSS 4
- Vite

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The original Lilac purple (`#782671`) and logo assets remain unchanged. Guest-facing state such as cart and saved items is stored locally in the browser.
